# 変更履歴

利用者に関わる変更をバージョンごとに記載する。

## v0.1.0

Suzの初版。

- 整数・浮動小数点数・真偽値・構造体・列挙型と、定数・変数・関数を提供する。
- 分岐・反復・パターン照合と、値を返す `ifexpr`・`matchexpr`・`expr` を提供する。
- 整数演算の実行時検査、ラップ演算、型変換、`or` による失敗処理を提供する。
- テンプレート文字列を使う `log info` と、ソース位置を示すパニック診断を提供する。
- `suz` にソース検査、実行ファイルのビルドと実行、C一式の出力を備える。ランタイムとRyuを内包し、ビルドには外部のClang・リンカー・SDKを使う。
- macOS・Apple Siliconを対象とする。
