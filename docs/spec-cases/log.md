### log-005 埋め込み式から別のログを出力する

主根拠：`[log.interpolation]`。

補助根拠：`[log.output]`。

**ソース：**

```suz
fn value() -> u8 {
    log info `inner`
    return 3
}

fn main() -> u8 {
    log info `outer: ${value()}`
    return 0
}
```

**期待結果：**

| 設定 | 結果 | 終了コード | 整数演算の警告数 |
|---|---|---:|---:|
| 通常 | 正常終了 | 0 | 0 |

外側のログは、valueの評価を終えてから出力を始める。valueが出すinnerの行が先に完了し、その後にouterの行が続く。

**標準エラー：**

```text
info log-005.suz:2: inner
info log-005.suz:7: outer: 3
```

### log-006 埋め込み式の評価中にパニックする

主根拠：`[log.interpolation]`。

補助根拠：`[rt.div-zero]`、`[rt.panic]`。

**ソース：**

```suz
fn divide(divisor: i32) -> i32 {
    log info `inner`
    return 1 / divisor
}

fn main() -> u8 {
    log info `outer: ${divide(0)}`
    return 0
}
```

**期待結果：**

| 設定 | 結果 | 終了コード | 整数演算の警告数 |
|---|---|---:|---:|
| 通常 | パニック | 101 | 0 |

divideはinnerを出力した後、ゼロ除算でパニックする。外側のログは埋め込み式の評価が完了していないため、接頭辞も本文も出力しない。

**パニック診断：**

| 設定 | 規則 | 行 | 列 |
|---|---|---:|---:|
| 通常 | `[rt.div-zero]` | 3 | 14 |

標準エラーは次の行で始まり、その後にlog-006.suzの3行目の除算でゼロ除算が起きたことを示すパニック診断が続く。

**パニック前の標準エラー：**

```text
info log-006.suz:2: inner
```

### log-009 bool・enum・整数のログ表示

主根拠：`[log.value-format]`。

補助根拠：`[log.output]`。

**ソース：**

```suz
enum Wave: u8 { Sine, Saw }

fn main() -> u8 {
    log info `${true} ${false} ${Wave.Saw} ${1_234} ${-7}`
    return 0
}
```

**期待結果：**

| 設定 | 結果 | 終了コード | 整数演算の警告数 |
|---|---|---:|---:|
| 通常 | 正常終了 | 0 | 0 |

enumは型名を付けず列挙子名だけを表示する。整数の区切りのアンダースコアは表示しない。

**標準エラー：**

```text
info log-009.suz:4: true false Saw 1234 -7
```

| 設定 | 結果 | 終了コード | 整数演算の警告数 |
