### prog-009 独立したブロックで同じ変数名を使う

主根拠：`[decl.shadowing]`。

補助根拠：`[decl.local-scope]`。

**ソース：**

```suz

    var total: u8 = 0
    {
        fix value: u8 = 1
        total += value
    }
    {
        fix value: u8 = 2
        total += value
    }
    return total
}
```

**期待結果：**

| 設定 | 結果 | 終了コード | 整数演算の警告数 |
|---|---|---:|---:|
| 通常 | 正常終了 | 3 | 0 |

2つのvalueのスコープは重ならない。
